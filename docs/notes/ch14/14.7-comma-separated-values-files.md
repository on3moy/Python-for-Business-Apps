# 14.7 Comma-separated values files  

CSVs are the Excel of text files. Rows and columns, no formatting. You will see these constantly in data analytics, pandas included.  

**csv file:**  
A text file where each line is a row and commas separate the fields.  

```
product,units,price
Widget,10,2.50
Gadget,4,12.00
```

## Reading  

The `csv` module gives you a **reader** object. Loop over it and each row is a list of strings.  

```
import csv

with open('products.csv', 'r') as csv_file:
    reader = csv.reader(csv_file)

    # Lets skip the header row
    header = next(reader)

    for row in reader:
        print(row)
```

Output of the first row: `['Widget', '10', '2.50']`  

!!! warning "Still strings"  

    `row[1]` is `'10'`, not `10`. Convert with `int()` or `float()` before doing math.  

??? example "🦖 Example"  

    ```
    import csv

    revenue = 0
    with open('products.csv', 'r') as csv_file:
        reader = csv.reader(csv_file)
        next(reader)

        # Lets multiply units by price for each row
        for row in reader:
            revenue += int(row[1]) * float(row[2])

    print(f'Revenue: {revenue:.2f}')
    ```  

??? question "What if a field has a comma in it?"  

    Wrap that field in quotes, like `"Smith, Jane"`, and the reader keeps it together. Or pass a different `delimiter`, like `csv.reader(csv_file, delimiter=';')`.  

## Writing  

```
import csv

rows = [['product', 'units'], ['Widget', '10'], ['Gadget', '4']]

# Lets use newline='' so we do not get blank lines on Windows
with open('out.csv', 'w', newline='') as csv_file:
    writer = csv.writer(csv_file)

    # writerow writes one row, writerows writes a list of rows
    writer.writerows(rows)
```
