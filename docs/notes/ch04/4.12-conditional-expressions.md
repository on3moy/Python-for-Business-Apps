# 4.12 Conditional expressions  

Sometimes a whole if-else exists just to put one of two values into one variable. There is a shorter way to write that.  

**conditional expression:**  
Takes the form `expr_when_true if condition else expr_when_false`.  

The condition in the middle is evaluated **first**. If it is True you get the left-hand value, otherwise you get the right-hand one.  

## Before and after  

The long way:  

```
# Lets set the shipping cost
if order_total > 50:
    shipping = 0
else:
    shipping = 7
```

The same thing as a conditional expression:  

```
# Lets set the shipping cost in one line
shipping = 0 if order_total > 50 else 7
```

Four lines become one, and it still reads like a sentence.  

??? example "🦖 Example"  

    ```
    # Lets label an account
    balance = 250

    status = 'overdrawn' if balance < 0 else 'ok'

    print(status)
    ```

    Output:  
    `ok`  

!!! note "Fun Fact"  

    Three operands means this is sometimes called a **ternary operation**. If you ever see that word in documentation, this is what it means.  

## Use it sparingly  

!!! tip "Good practice"  

    Keep conditional expressions to simple assignment statements, like the examples above.  

    Plenty of Python developers dislike them, and the complaint is fair: the middle operand is evaluated first, which is not how we read English. One short line is fine. Nesting them is not.  

??? question "So when should I just write the if-else?"  

    When the branches do more than produce a value. The moment you want to print something, update a second variable, or the condition itself gets long, go back to a normal if-else. Clever is not the goal — the goal is that the next person understands it immediately.
