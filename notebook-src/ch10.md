## 10.3 Instance methods

An instance method is a function defined inside a class, called on an instance with dot notation. It takes `self` first, just like `__init__`, even though you never pass an argument for it yourself.


## 10.4 Class and instance object types -- a class attribute is shared

A class attribute is defined in the body of the class itself and is shared by every instance -- there's only one copy of it to read.

## 10.4 Class and instance object types -- an instance attribute is not

An instance attribute, usually created with `self.attr = value` inside a method, belongs to one specific instance and is completely separate from every other instance's copy.

```python

    def __init__(self):
```

## 10.5 Class example: Putting it together

One class can manage a collection of instances of another. `LineItem` only knows how to describe and total itself; `Invoice` manages a list of them without needing to know how each one computes its own total.

```python
class LineItem:
    def __init__(self, description, hours, rate):
        self.description = description
        self.hours = hours
        self.rate = rate

    def total(self):
        return self.hours * self.rate

class Invoice:
    def __init__(self, client_name):
```

## 10.7 Class interfaces

The class interface is the set of methods a caller is meant to use. A leading underscore on a method name (like `_diff_time`) signals internal plumbing that isn't part of that interface -- Python doesn't enforce it, but it tells a reader not to depend on it directly.

```python
class RaceTime:
    def __init__(self, start_hrs, start_mins, end_hrs, end_mins, dist):
        self.start_hrs = start_hrs
        self.start_mins = start_mins
        self.end_hrs = end_hrs
        self.end_mins = end_mins
        self.distance = dist

    def print_pace(self):
        total_time = self._diff_time()
        total_minutes = total_time[0] * 60 + total_time[1]
        print(f'Avg pace (mins/mile): {total_minutes / self.distance:.2f}')
```

## 10.9 More operator overloading: Classes as numeric types -- arithmetic operators

Arithmetic operators can be overloaded too. `time1 - time2` calls `time1.__sub__(time2)`, and the method can hand back a brand-new instance holding the result.

```python
class Time24:
    def __init__(self, hours, minutes):
        self.hours = hours
        self.minutes = minutes

    def __str__(self):
        return f'{self.hours:02d}:{self.minutes:02d}'

    def __gt__(self, other):
        if self.hours > other.hours:
            return True
        return self.hours == other.hours and self.minutes > other.minutes
```
