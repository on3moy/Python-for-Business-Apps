# 14.1 Reading files  

Most of the data you will touch in analytics lives in a file, not in a variable you typed. Lets learn how to pull it in.  

**file object:**  
What `open()` hands back. It is your connection to the file on disk.  

**EOF:**  
End-of-file. The point where there is no more data left to read.  

```
# Lets open the file, this gives us a file object
sales_file = open('sales.txt')

# Lets read everything into one string
contents = sales_file.read()

# Lets close it when we are done
sales_file.close()
print(contents)
```

The path is relative to where your script is running. A full path works too.  

!!! abstract "Ways to read"  

    - **read()** returns the whole file as one string  
    - **readlines()** returns a list of strings, one per line  
    - **readline()** returns one line at a time (great for files too big for memory)  

??? question "Why does my number not add up?"  

    Everything you read from a file is a string, even `105`. You have to convert it with `int()` or `float()` first. Same idea as `input()` 😓  

??? example "🦖 Example"  

    ```
    # Lets read a file of daily order totals, one number per line
    orders_file = open('orders.txt')
    lines = orders_file.readlines()
    orders_file.close()

    # Lets add them up, converting each line
    total = 0
    for line in lines:
        total += int(line)

    # Lets get the average
    print(f'Average order: {total / len(lines)}')
    ```  

Files are iterable, so you can skip the list and loop right on the file object.  

```
# Lets loop over the file line by line
orders_file = open('orders.txt')
for line in orders_file:
    print(line, end='')
orders_file.close()
```

Each line already ends in `\n`, so we use `end=''` to avoid double spacing.  

If the file is missing you get a `FileNotFoundError`. You already know how to deal with that from [handling exceptions](../ch12/12.1-handling-exceptions-using-try-and-except.md).
