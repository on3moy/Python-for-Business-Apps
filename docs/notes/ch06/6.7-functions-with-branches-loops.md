# 6.7 Functions with branches/loops  

Nothing about being inside a function changes the rules you already know — [if-else branches](../ch04/4.1-if-else-branches.md) and [for loops](../ch05/5.5-for-loops.md) work exactly the same whether they live in the main program or inside a `def` block. This section is really just proof of that.  

??? example "🦖 Example — eBay-style fee calculator"  

    ```
    def calc_ebay_fee(sell_price):
        '''Fee is $0.50 to list plus 13% up to $50,
        5% from $50.01-$1000, 2% above $1000.'''
        fee = 0.50
        if sell_price <= 50:
            fee += sell_price * 0.13
        elif sell_price <= 1000:
            fee += (50 * 0.13) + ((sell_price - 50) * 0.05)
        else:
            fee += (50 * 0.13) + (950 * 0.05) + ((sell_price - 1000) * 0.02)
        return fee

    print(f'eBay fee: ${calc_ebay_fee(100):.2f}')
    ```

    Output: `eBay fee: $9.50`

    Same tiered-pricing pattern you'd write with a plain `if`/`elif`/`else` chain — it just happens to live inside a function this time, and the function hands back a single `fee` at the end instead of printing it directly.  

## Why this combination matters for business logic

Fee schedules, tax brackets, shipping tiers, commission structures — almost every "it depends on which range the number falls into" calculation you'll build for a business ends up looking exactly like `calc_ebay_fee()`: a branch to pick the right formula, wrapped in a function so the rest of the program can just ask for the answer.  

!!! note "Note"  

    The example above uses a line continuation (`\`) in the original zyBooks version to split a long `else` calculation across two lines. You'll rarely need that if you keep each branch's math to one readable line — but it's legal Python if a formula genuinely won't fit.  

??? question "How many assignment statements run for any single call?"  

    Exactly one — whichever branch matches gets its `fee +=` line executed, and the others are skipped entirely. That's the whole point of `elif`: only one branch in the chain ever runs.
