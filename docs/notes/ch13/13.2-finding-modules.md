# 13.2 Finding modules  

You typed `import something`. Where does Python even look for it?  

**sys.path:**  
A list of directories Python searches, in order, when you import a module.  

Python checks for a built-in module first. If it isn't one, it walks through `sys.path`, which starts with:  

1. The folder of the script you are running  
2. Folders listed in the `PYTHONPATH` environment variable  
3. The folder where Python is installed  

```
# Lets peek at where Python searches
import sys
print(sys.path)
```

!!! warning "Do not name your file math.py"  

    Built-in names are checked first. If you create `math.py`, `import math` still grabs the real one, and your file just sits there ignored 🥲. Same goes for `random.py`, `time.py`, `sys.py`...  

??? question "What is PYTHONPATH?"  

    An **environment variable** is like a variable in Python, except your operating system stores it and every program can read it.  

    `PYTHONPATH` lets you add extra folders to `sys.path` without changing code. Handy when a team keeps shared reporting modules in one central folder.  

For simple projects, just keep the module next to your script. Done. If you are new to modules, start with [what a module is](13.1-modules.md).
