# 4.2 Detecting equal values  

Most business logic starts with a question: is this thing equal to that thing?  

**equality operator:**  
The `==` operator evaluates to True if the left and right sides are equal.  

**inequality operator:**  
The `!=` operator evaluates to True if the two sides are different.  

!!! warning "The single most common beginner error"  

    `=` assigns. `==` compares. They are not interchangeable.  
    `if num_years == 50:` ✅  
    `if num_years = 50:` ❌ (syntax error)  

    You will do this. Everyone does this. Now you know what the error means.  

**Boolean:**  
A type with exactly two values, True or False.  

## The operators  

|Operator|Description|Example, x is 3|  
|-|-|-|  
|`==`|a is equal to b|`x == 3` is True, `x == 4` is False|  
|`!=`|a is not equal to b|`x != 3` is False, `x != 4` is True|  

## Even or odd  

Pair `==` with the [modulo operator](../ch02/2.7-division-modulo.md) and you get the classic.  

```
# Lets check if a number is even
user_num = 22
div_remainder = user_num % 2

if div_remainder == 0:
    print(f'{user_num} is even.')
else:
    print(f'{user_num} is odd.')
```

Output:  
`22 is even.`  

## Multi-branch  

??? example "🦖 Example"  

    Lets route an invoice based on its status code.  

    ```
    # Lets decide what happens to this invoice
    status = 'overdue'

    if status == 'paid':
        print('File it.')
    elif status == 'pending':
        print('Wait.')
    elif status == 'overdue':
        print('Send a reminder.')
    else:
        print('Unknown status, flag for review.')
    ```

    Output:  
    `Send a reminder.`  

??? question "Why not just use a bunch of separate if statements?"  

    Because elif stops as soon as one matches. Separate if statements all get checked, and more than one can fire. That difference will bite you eventually, so we cover it properly in [detecting multiple features](4.7-multiple-features.md).
