# 8.4 Splitting and Joining Strings

Lets talk about two methods that are basically opposites of each other, and are how you'll actually break apart a messy line of text (like a CSV row) and put it back together the right way.  

## split()

**split():**
`split()` breaks a string into a [list](../ch03/3.2-list-basics.md) of tokens, using whitespace as the default separator. Pass a string argument to split on something else instead.  

```
sentence = 'Martin Luther King Jr.'
print(sentence.split())
```

Output:
`['Martin', 'Luther', 'King', 'Jr.']`

```
url = 'en.wikipedia.org/wiki/ethernet/'
tokens = url.split('/')
print(tokens)
```

Output:
`['en.wikipedia.org', 'wiki', 'ethernet', '']`

!!! warning "A leading, trailing, or doubled-up separator leaves empty strings behind"

    Notice the trailing `''` above — the URL ended in `/`, so `split()` had nothing left to grab after it and still gave you a slot for it. Two separators back to back do the same thing. This only happens when you pass a separator explicitly; splitting on the default whitespace never produces empty strings.  

## join()

**join():**
`join()` does the reverse of `split()` — it glues a list of strings into one string, with the separator you call it on placed between every element.  

Input:
`'@'.join(['billgates', 'microsoft'])`
Output:
`'billgates@microsoft'`

The separator can even be an empty string `''`, which just mushes everything together with nothing between the pieces.  

??? example "🦖 Example"

    Building one sentence out of a list of phrases with a loop works, but `join()` gets there in one line.  

    ```
    phrases = ['To be, ', 'or not to be.\n', 'That is the question.']

    sentence = ''.join(phrases)
    print(sentence)
    ```

    Output:
    ```
    To be, or not to be.
    That is the question.
    ```

## Using split() and join() together

The real power move is pairing them up: split a string apart on one separator, edit the pieces, then join them back with a different one.  

```
path = 'C:/Users/Wolfman/Documents/report.pdf'

tokens = path.split('/')
print('\\'.join(tokens))
```

Output:
`C:\Users\Wolfman\Documents\report.pdf`

??? question "Why not just use replace() for this instead?"

    `replace()` works great for a simple character swap, like `/` to `\`. But `split()`/`join()` gives you a list in the middle — which means you can also `insert()`, remove, or check individual tokens before rejoining, not just swap characters. If a Wikipedia URL is missing its `/wiki/` segment, you can insert it at exactly the right index before you rebuild the string. `replace()` can't do that.  

    ```
    url = 'http://en.wikipedia.org/Rome'
    tokens = url.split('/')

    if 'wiki' != tokens[3]:
        tokens.insert(3, 'wiki')

    print('/'.join(tokens))
    ```

    Output:
    `http://en.wikipedia.org/wiki/Rome`
