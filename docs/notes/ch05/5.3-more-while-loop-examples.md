# 5.3 More while loop examples  

A few more patterns worth seeing before we move on to for loops.  

## Peeling off digits

`%` and `//` together let you pull a number apart one digit at a time, starting from the right. If you have not looked at [division and modulo](../ch02/2.7-division-modulo.md) in a while, this is a good moment to refresh it.  

??? example "🦖 Example"  

    ```
    num = 902

    while num > 0:
        print(num % 10)
        num = num // 10
    ```

    Output:  
    ```
    2
    0
    9
    ```

    `902 % 10` is `2`, the rightmost digit. `902 // 10` is `90`, the number with that digit chopped off. Repeat until nothing is left.  

## Greatest common divisor

Euclid's algorithm is a nice while loop workout: keep subtracting the smaller number from the larger one until both are equal, and that equal value is the GCD.  

```
num_a = 15
num_b = 10

while num_a != num_b:
    if num_a > num_b:
        num_a = num_a - num_b
    else:
        num_b = num_b - num_a

print(num_a)
```

Output:  
`5`  

## Random conversation

The `random` module can drive a while loop too — the loop keeps talking until the user types a stop word, and which branch runs each time is decided by a random number.  

```
import random

user_text = ''

while user_text != 'goodbye':
    user_text = input('Say something: ')
    reply = random.randint(0, 2)

    if reply == 0:
        print('Interesting.')
    elif reply == 1:
        print('Tell me more.')
    else:
        print('Got it.')
```

??? question "How is this different from the docstring in the raw zyBooks example?"  

    A docstring is just a multi-line string literal, delimited by triple quotes, sitting at the top of a function or program to describe what it does. It does not change how the loop runs at all — Python just skips over it as a statement that evaluates to a string and throws the value away. It is documentation, not logic.  

## Ending on a sentinel that is not a keyword

Same shape as the password example from [while loops](5.2-while-loops.md), but with numbers: keep summing input values until 0 shows up, then report the average of everything before it.  

```
values_sum = 0
num_values = 0
val = int(input('Enter a value, or 0 to stop: '))

while val != 0:
    values_sum = values_sum + val
    num_values = num_values + 1
    val = int(input('Enter a value, or 0 to stop: '))

print(values_sum / num_values)
```

!!! note "Note"  

    That last line will crash with a `ZeroDivisionError` if the very first input is `0` — `num_values` is still `0` at that point. Sentinel-driven loops that compute an average almost always need a guard for "nothing was ever entered."
