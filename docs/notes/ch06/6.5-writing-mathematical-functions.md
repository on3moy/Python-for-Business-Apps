# 6.5 Writing mathematical functions  

A function that takes numbers in and hands a number back is the easiest kind to reason about — it behaves exactly like a math class function you'd graph, `f(x)`.  

```
def height_us_to_cm(feet, inches):
    total_inches = (feet * 12) + inches
    return total_inches * 2.54
```

## Function calls inside expressions

**A function call evaluates to whatever it returns**, which means you can drop it directly into a larger expression the same way you'd drop in a variable.  

```
def compute_square(num_to_square):
    return num_to_square * num_to_square

c2 = compute_square(7) + compute_square(9)
print(f'7 squared plus 9 squared is {c2}')
```

Output: `7 squared plus 9 squared is 130`

- ✅ `y = 1.0 + square_root(144.0)` — the call resolves to a number first, then the addition happens
- ✅ `y = square_root(square_root(16.0))` — nesting works fine, inner call resolves first
- ❌ `square_root(49.0) = z` — you can't assign *to* a function call, only *from* one
- ❌ `y = print_val(9.0)` — assigning a [void function's](6.2-print-functions.md) call to `y` just gives you `None`

## Modular math functions

Bigger mathematical functions lean on smaller ones instead of reinventing them. A cylinder's volume and surface area both need the area of its circular base, so write that once and call it twice.  

```
import math

def calc_circular_base_area(radius):
    return math.pi * radius * radius

def calc_cylinder_volume(radius, height):
    return calc_circular_base_area(radius) * height
```

This is the same [objects](../ch02/2.3-objects.md) idea from Chapter 2 applied at a bigger scale — `calc_circular_base_area()` doesn't care who's calling it, it just takes a radius and hands back an area, which is exactly why `calc_cylinder_volume()` can lean on it without knowing anything about pi under the hood.  

!!! note "Fun Fact"  

    `math.sqrt()` and `math.pi` from the [math module](../ch02/2.9-math-module.md) are themselves just functions and constants somebody else already wrote for this exact reason — don't rebuild what's already sitting in the standard library.
