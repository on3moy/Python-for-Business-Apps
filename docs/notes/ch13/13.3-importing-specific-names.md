# 13.3 Importing specific names  

Typing `pay_tools.net_pay` every time gets old. You can grab just the names you need.  

**from import:**  
Copies only the names you list from a module into your own namespace.  

```
# Lets import the whole module
import pay_tools
print(pay_tools.net_pay(5000))

# Lets import only the function, no prefix needed
from pay_tools import net_pay
print(net_pay(5000))
```

|Style|Import|Use|
|-|-|-|
|Whole module|`import pay_tools`|`pay_tools.net_pay(5000)`|
|Specific name|`from pay_tools import net_pay`|`net_pay(5000)`|

You can pull in more than one name with commas: `from pay_tools import net_pay, TAX_RATE`  

!!! warning "Avoid import *"  

    `from pay_tools import *` dumps every name into your file. Now nobody (including you) can tell where `net_pay` came from ❌  
    Fine for quick poking around in the interpreter. Skip it in real scripts.  

??? question "Which one should I use?"  

    - A few names used a lot? `from` ✅  
    - Lots of names, or names that might clash with your own variables? `import module` ✅  

??? example "🦖 Example"  

    ```
    # Lets use the standard library to hash a customer id
    from hashlib import sha256

    # Hashing needs bytes, so we encode the text first
    customer_id = 'C-1001'
    print(sha256(customer_id.encode('utf-8')).hexdigest())
    ```

    A hash is a fingerprint. Same text in, same hash out, which is handy for checking that data did not change.
