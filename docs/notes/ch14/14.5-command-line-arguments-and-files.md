# 14.5 Command-line arguments and files  

Hardcoding `'sales_march.txt'` means editing the script every month. Let the person running it pass the filename in.  

**command-line argument:**  
A value typed after the script name when you run it.  

`sys.argv` is a list of those. `sys.argv[0]` is the script itself, `sys.argv[1]` is the first argument.  

```
python load_sales.py sales_march.txt
```

`sys` and `os` are imported like any other [module](../ch13/13.1-modules.md).  

??? example "🦖 Example"  

    ```
    import sys
    import os

    # Lets make sure we got exactly one argument
    if len(sys.argv) != 2:
        print(f'Usage: {sys.argv[0]} input_file')
        sys.exit(1)

    file_name = sys.argv[1]

    # Lets make sure the file is really there
    if not os.path.exists(file_name):
        print('File does not exist.')
        sys.exit(1)

    # Lets read the first line as a number
    sales_file = open(file_name)
    first_amount = int(sales_file.readline())
    sales_file.close()
    print(f'First amount: {first_amount}')
    ```  

!!! info "Exit codes"  

    `sys.exit(1)` stops the script and tells the operating system something went wrong. `0` means success. Schedulers and automation tools read this to know if your job failed.  

!!! warning "Every argument is a string"  

    Even `python script.py 5` gives you `'5'`. Convert it.
