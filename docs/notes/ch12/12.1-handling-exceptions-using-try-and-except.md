# 12.1 Handling exceptions using try and except  

Your script will crash at some point. Usually because someone typed something you didn't expect. Lets learn how to keep it running 🛟.  

**exception:**  
An error that happens while the program is running and stops it, unless you handle it.  

**exception handling:**  
Responding to an error in your code so the program can keep going instead of dying.  

## What a crash looks like

Say you are reading a sales amount from a user.  

```
# Lets ask for a number
sales = int(input('Enter sales: '))
print(sales * 0.07)

# If the user types 'lots', we get a ValueError and the script stops
```

Output:  
`ValueError: invalid literal for int() with base 10: 'lots'`  

## try and except

Put the risky code in a **try** block. If something goes wrong, Python jumps to the **except** block and then carries on after it.  

```
try:
    # Lets put the risky code here
    sales = int(input('Enter sales: '))
    print(sales * 0.07)
except:
    # Lets run this only if something broke above
    print('Could not calculate tax')

print('Still running!')
```

- No error: the `except` block is skipped ✅  
- Error: the rest of the `try` block is skipped and `except` runs ✅  
- The line after the `except` always runs ➡️  

??? question "After the error, does Python go back to the line that failed?"  

    No. It never returns to the `try` block. It runs the `except` block and keeps moving down the file. If you want to ask the user again, put the `try` inside a `while` loop like in [while loops](../ch05/5.2-while-loops.md).  

## Common exception types

|Type|Raised when|  
|-|-|  
|`EOFError`|`input()` hits the end of the file without reading anything|  
|`KeyError`|A dictionary key is not found|  
|`ZeroDivisionError`|You divided by zero|  
|`ValueError`|The value is wrong, like `int('abc')`|  
|`IndexError`|The index is out of bounds|  

??? example "🦖 Example"  

    ```
    # Lets keep asking until the user gives us a number
    amount = None
    while amount is None:
        try:
            amount = float(input('Invoice amount: '))
        except:
            print('Numbers only please 🥲')
    ```
