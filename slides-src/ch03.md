# 3.1 String Basics

---

## String

A sequence of characters, like `'MARY'`, stored in a variable.

A **sequence type** is ordered left to right — that ordering is what makes
slicing possible.

```python
len('moy')
```

Output: `3`

---

## Slicing with `[]`

Let's use `'wowmom'`.

```python
'wowmom'[0]     # first letter -> 'w'
'wowmom'[:3]    # 'wow'
'wowmom'[3:]    # 'mom'
'wowmom'[3:7]   # also 'mom'
```

The index always starts at 0, and the end of a range is exclusive.

<!--
Emphasize the off-by-one: to grab indexes 0-5 you slice [:6], not [:5].
This is the single most common slicing bug students hit.
-->

---

## Strings are immutable

```python
alphabet = 'abcdefghijklmnopqrstuvwxyz'

alphabet[0] = 'A'  # Invalid: cannot change a character
```

Once created, a string cannot be edited in place — you build a new one.

# 3.2 List Basics

---

## List

A container — square brackets around a sequence of variables or literals.

```python
hey_you = 15
[13.0, '13', 'hi', hey_you]
```

A list can mix types freely. Each item is an **element**, indexed from 0.

<!--
Similar to a column in Excel, except a column usually holds one type and a
list will happily hold whatever you put in it.
-->

---

## append() vs concatenation

<div class="columns">
<div>

## Concatenate
```python
x = [1, 2]
y = [3, 4]
added = x + y
```
Makes a new list.

</div>
<div>

## append()
```python
x = [1, 2]
x.append(3)
x.append(4)
```
Changes `x` in place — one
element at a time.

</div>
</div>

Output of x: `[1, 2, 3, 4]`

---

## pop() and remove()

```python
somelist = ['hi', 13, 'Friday']
extract_last_element = somelist.pop()
print(somelist)
print(extract_last_element)
```

Output: `['hi', 13]` then `'Friday'`

`pop()` removes (and returns) the last element by default. `remove()` deletes
by value, not position.

---

## Modifying and measuring

```python
list_a = [13, 14, 15]
list_a[0] = 'WOW'
print(list_a)
```

Output: `['WOW', 14, 15]`

`len()`, `min()`, `max()`, `sum()`, `.index(val)`, `.count(val)` all work on
lists too — same names you already know from 2.9.

# 3.3 Tuple Basics

---

## Tuple

Like a list, but **immutable** — once created, it cannot change.

Use it for values that should stay fixed for everyone: weekday names, a
calendar, category labels.

```python
weekdays = ('Mon', 'Tue', 'Wed', 'Thu', 'Fri')
weekdays[0] = 'Monday'
```

That last line ❌ — same protection strings get.

<!--
Named tuples exist (from collections import namedtuple) but skip them —
not something you'll reach for in data analytics work. Classes cover this
need later and better.
-->

# 3.4 Dictionary Basics

---

## Dictionary

Key:value pairs inside curly braces `{}`.

```python
beans = {
    'professor': 'Moy'
    ,'student': 'Stephanie'
}
```

**Key:** a lookup term, like `'cat'` in a dictionary.
**Value:** the data tied to that key.

<!--
Fun fact for the room: dictionaries didn't used to preserve insertion order
in Python. They do now — which is exactly what makes them useful for
building tables and reports.
-->

---

## Don't confuse with a set

`set()` also uses `{}`. The difference is what's inside.

```python
some_set = {'a', 'b', 'c'}
some_dict = {'key': 'value', 'Wizard': 'Harry Potter'}
```

No colon, just commas → a set. Colons pairing items → a dictionary.

`{}` alone is an **empty dictionary**, not an empty set.

---

## Working with a dictionary

```python
beans['black beans'] = 'They make you gassy'   # add
del beans['professor']                          # delete

beans['student']    # grab one value
beans.keys()         # all keys
beans.values()        # all values
beans.items()          # all key/value pairs
```

<!--
This is the shape of almost every JSON payload from an API call. Worth
saying out loud — dictionaries are the bridge between JSON and pandas.
-->

# 3.10 String Formatting

---

## The old way vs the new way

```python
student = 'John Doe'
color = 'purple'

# Old: .format()
print('Hi my name is {}. {} is my favorite color'.format(student, color))

# New: f-string
print(f'Hi my name is {student}. {color} is my favorite color')
```

Use f-strings. They read left to right, in the order the values fill in.

---

## Why f-strings

- Auto-fill an email template with a name, subject, body
- Build a report line from live variables
- `print(f'I am {years_variable} old.')`

An `f` before the opening quote is the whole trick.
