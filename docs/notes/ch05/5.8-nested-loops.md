**nested loop:**  
A loop that lives inside the body of another loop. The outer loop and inner loop each keep their own variable and their own condition.  

The reason to reach for this: generating every **combination** of two things. One item from list A paired against every item in list B, then the next item from A against every item in B, and so on.  

??? example "🦖 Example"  

    Two-letter domain names — every letter paired against every other letter.  

    ```
    letter1 = 'a'

    while letter1 <= 'z':
        letter2 = 'a'
        while letter2 <= 'z':
            print(f'{letter1}{letter2}.com')
            letter2 = chr(ord(letter2) + 1)
        letter1 = chr(ord(letter1) + 1)
    ```

    Output (partial):  
    ```
    aa.com
    ab.com
    ...
    zz.com
    ```

    `ord()` and `chr()` are how you step through letters like numbers — `ord('a')` gives you the underlying integer, and `chr()` converts an integer back into a character. Worth reviewing [representing text](../ch02/2.11-representing-text.md) if that pair feels unfamiliar.  

    For **every single pass** of the outer loop, the entire inner loop runs start to finish. That is why 26 outer passes times 26 inner passes gives you all 676 two-letter combinations.  

## How many times does the inner body actually run?

??? question "If the outer loop runs 5 times and the inner loop runs 3 times, how many times does the inner body execute?"  

    15 — not 5, not 3, and not 8. Multiply, do not add. The inner loop restarts fully on every single outer iteration.  

    ```
    for i in range(5):
        for j in range(3):
            print(f'{i},{j}')
    ```

    That prints 15 lines total, `i` staying fixed while `j` runs 0, 1, 2 underneath it each time.  

## Building a grid

Nested for loops are the natural way to print anything shaped like rows and columns — a rectangle of asterisks, seat labels in a theater, a table of numbers.  

```
num_rows = 2
num_cols = 3

for row in range(num_rows):
    for col in range(num_cols):
        print('*', end=' ')
    print()
```

Output:  
```
* * *
* * *
```

The outer loop picks the row, the inner loop fills that entire row before the outer loop moves on to the next one.
