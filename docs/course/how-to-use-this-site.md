# How to Use This Site

This site is not really a textbook you read front to back. The zyBook already
does that job. This is the pile of notes I take into lecture, wired together so
you can pull out the one thing you actually need at 11pm the night before an
assignment is due.

Here's how to get at it.

## Search is the fastest way in

Press <kbd>S</kbd> anywhere and start typing. Search covers the full text of
every note, so `modulo` or `dictionary` will get you there faster than
clicking through the nav. One quirk to know: the search box splits on hyphens,
so a hyphenated term like `f-string` won't match — search `fstring` or
`formatting` instead.

## Cross-references, where they exist

Some notes link out to related sections elsewhere in the site — follow those
when you see them. Cross-linking is still sparse in the older chapters, so
don't count on it as your main way to find something; search is the more
reliable path for now.

## Chapter hubs

Each chapter has a landing page listing its sections in order with a one-line
description. If you *do* want to read a chapter straight through, start there.

## Slides

Lecture decks live under [Slides](../slides/index.md). Ctrl + Click to open one
in a new tab, then press <kbd>F</kbd> for fullscreen.

## Notebooks

A handful of chapters also have a runnable Jupyter notebook version, under the
**Notebooks** tab in the nav — same material, in a format you can execute cell
by cell. Start with the
[Python Crash Course](../notebooks/python-crash-course.ipynb) notebook if
you're not sure where to begin.

## Dark mode

Top right, next to the search bar. Your eyes will thank you.
