# 5.4 Counting  

Counting iterations is such a common job for a loop that it gets its own section. The pattern: a variable starts at some value, gets updated by the same amount every pass through [a while loop](5.2-while-loops.md), and the loop stops once it crosses a limit.  

??? example "🦖 Example"  

    ```
    loop_variable = 1

    while loop_variable <= 5:
        print(loop_variable)
        loop_variable = loop_variable + 1
    ```

    Output:  
    ```
    1
    2
    3
    4
    5
    ```

    `loop_variable` starts at 1 and climbs by 1 each time. The instant it hits 6, `6 <= 5` is False and the loop is done. That is why the count stops at 5, not 6 — the check happens before the print.  

!!! warning "The forgotten update, again"  

    Leave off `loop_variable = loop_variable + 1` and you get the same infinite loop bug from a couple pages back, just wearing a counting costume this time. It is the single most common bug in this chapter.  

## Counting down, and counting by other amounts

Nothing says you have to count by 1s upward. Decrement instead of increment, or step by any amount you like.  

```
variation = 10

while variation >= 0:
    print(variation)
    variation -= 5
```

Output:  
```
10
5
0
```

## Compound operators

`+=`, `-=`, `*=`, `/=` are shorthand for "take the variable, do the operation, and reassign it."  

|Operator|Meaning|
|-|-|
|`x += 5`|`x = x + 5`|
|`x -= 5`|`x = x - 5`|
|`x *= 5`|`x = x * 5`|
|`x /= 5`|`x = x / 5`|

Change the operator and you usually also need to change how the variable was initialized and what the condition checks — a loop that multiplies to count 1, 10, 100 needs `*=`, not `+=`, and the condition needs an upper bound that a multiplication will actually reach.  

## Counting shows up in real formulas

A running factorial, a Fibonacci sequence, a savings balance that compounds interest year over year — all of these are just a counting loop with one extra line of math tucked inside the body.  

```
factorial = 4
count = factorial - 1

while count >= 1:
    factorial *= count
    count -= 1

print(f'4! = {factorial}')
```

Output:  
`4! = 24`
