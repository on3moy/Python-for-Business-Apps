# 9.1 Lists

We already covered the fundamentals in [list basics](../ch03/3.2-list-basics.md) — brackets, indexing, append/pop. This section is about a habit you need to build now that programs get bigger: knowing when you're modifying a list in place versus just reassigning a name.  

**container:**
A list is a mutable container — it groups related objects together and its size can grow or shrink after creation.  

**list():**
The built-in `list()` function turns any iterable (a string, tuple, another list) into a new list. `list('abc')` gives you `['a', 'b', 'c']`.  

## In-place modification has side effects

Here's the part that trips people up. If two variable names point at the same list object, changing the list through one name changes what the other name sees too.  

??? example "🦖 Example"

    ```
    my_teams = ['Lakers', 'Dodgers']
    your_teams = my_teams

    # Lets change my_teams
    my_teams[0] = 'Rams'

    print(your_teams)
    ```

    Output:
    `['Rams', 'Dodgers']`

    `your_teams` never asked to change, but `my_teams = my_teams` didn't copy anything — it just handed `your_teams` a reference to the exact same list object.  

!!! warning "Reassigning a variable is not the same as modifying the list"

    `fav_color = colors[2]` binds `fav_color` to whatever value lived at that index. Reassigning `fav_color` afterward — `fav_color = 'turquoise'` — does not touch `colors`. Only indexed assignment (`colors[1] = 'yellow'`) or a list method reaches into the shared object.  

## Making an actual copy

If you want a separate list, not another name for the same one, slice the whole thing.  

```
my_teams = ['Lakers', 'Dodgers']

# Lets make a real copy this time, not a shared reference
your_teams = my_teams[:]
your_teams[0] = 'Rams'

print(my_teams)
print(your_teams)
```

Output:
```
['Lakers', 'Dodgers']
['Rams', 'Dodgers']
```

!!! tip "This matters for reports"

    Imagine `my_teams` is a list of `sales_targets` you hand off to two different regions. If both variables reference the same list, one region editing their number silently edits the other's too. `[:]` is your insurance policy.
