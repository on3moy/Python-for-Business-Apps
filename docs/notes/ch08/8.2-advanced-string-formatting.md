# 8.2 Advanced String Formatting

We covered the basics of [f-strings](../ch03/3.10-string-formatting.md) already — dropping variables into `{}`. Now lets make those variables line up in nice, readable columns, the way a report or an export to Excel actually should look.  

**field width:**
A field width is the minimum number of characters a format specification will insert, padding with spaces if the value is shorter. It's set with an integer right after the colon, like `{name:16}`.  

```
name = 'Sadio Mane'
goals = 22

print(f'{name:16}{goals:8}')
```

Numbers are right-aligned inside their width by default, and strings are left-aligned by default. That's exactly backwards from what you'd guess, so watch it.  

## Aligning text

A format specification can force the alignment instead of relying on the default. The character goes right before the width number.  

| Symbol | Alignment |
|-|-|
| `<` | left-aligned |
| `>` | right-aligned |
| `^` | centered |

??? example "🦖 Example"

    ```
    names = ['Sadio Mane', 'Gabriel Jesus']
    goals = [22, 7]

    for i in range(2):
        print(f'{names[i]:<16}{goals[i]:<8}')
    ```

    Output:
    ```
    Sadio Mane      22
    Gabriel Jesus   7
    ```

    Swap the `<` for `^` and both columns center themselves inside their own width instead.  

## Fill characters

The fill character is what pads the extra space in the field — the default is just a blank space `' '`. You can set your own by putting it *before* the alignment symbol.  

Input:
`f"{9:0>4}"`(1)
Output:
`'0009'`
{ .annotate }

1. Fill with `0`, right-align (`>`), width 4.

!!! tip "Reading a format spec left to right"

    `{score:0>4}` reads as: fill with `0`, align `>` (right), width `4`. Zero-padding a score or an invoice number is exactly why this exists — nobody wants invoice `47` sitting next to invoice `00312`.  

## Floating-point precision

**precision:**
Precision is the number of digits shown to the right of the decimal point on a float, set with a period and an integer after the width in a format specification. Ex: `.2f` means 2 digits after the decimal.  

```
import math

real_pi = math.pi
approximate_pi = 22.0 / 7.0

print(f'22/7 looks better like {approximate_pi:.2f}')
```

Output:
`22/7 looks better like 3.14`

- `f"{1.5:.3f}"` → `'1.500'` ✅ pads with trailing zeros if there aren't enough digits
- `f"{1.666:.2f}"` → `'1.67'` ✅ rounds if there are too many

You can also combine a width and a precision in one spec, width first: `f"{approximate_pi:8.2f}"` reserves 8 characters total and shows 2 decimals inside that space.
