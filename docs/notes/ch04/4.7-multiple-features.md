# 4.7 Multiple features  

Two arrangements of if statements look nearly identical and behave completely differently. This section is about not mixing them up.  

## Separate if statements  

Each `if` is independent. Every one gets checked, and **more than one can run**.  

```
# Lets tag this account with everything that applies
balance = 5000
years = 8

if balance > 1000:
    print('Premium')
if years > 5:
    print('Loyal')
```

Output:  
```
Premium
Loyal
```

Both printed. That is the point.  

## Multi-branch if-else  

Chain them with `elif` and **exactly one** runs.  

```
# Lets pick a single tier for this account
if balance > 1000:
    print('Premium')
elif years > 5:
    print('Loyal')
```

Output:  
`Premium`  

"Loyal" never prints, even though it is true, because the first branch already won.  

!!! warning "Do not confuse these"  

    Separate `if` = "tag everything that applies".  
    `if` / `elif` = "pick exactly one".  

    Same-looking code, completely different report at the end of the month.  

## Nested if-else  

**nested if-else:**  
An if-else statement living inside another branch.  

??? example "🦖 Example"  

    Lets work out a sales bonus that depends on two things.  

    ```
    # Lets calculate the bonus
    sales_type = 2
    sales_bonus = 3

    if sales_type == 2:
        if sales_bonus < 5:
            sales_bonus = 10
        else:
            sales_bonus = sales_bonus + 2
    else:
        sales_bonus = sales_bonus + 1

    print(sales_bonus)
    ```

    Output:  
    `10`  

    The inner if is only reached at all when `sales_type == 2`.  

??? question "How deep should I nest?"  

    Two levels is usually fine. Three and it gets hard to hold in your head. If you find yourself at four, that is a strong hint the conditions want combining with [logical operators](4.5-logical-operators.md) instead.  

Every level of nesting is another level of [indentation](4.11-code-blocks-indentation.md), and Python is reading that indentation to work out what belongs to what.
