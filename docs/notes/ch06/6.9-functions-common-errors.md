# 6.9 Functions: Common errors  

YES! We all write buggy functions sometimes and its okay. Here are the ones you're most likely to hit.  

## Copy-paste errors

Writing a Fahrenheit-to-Celsius function, then copying it to make a Celsius-to-Fahrenheit function, is a completely reasonable time-saver — right up until you forget to change every single thing that needed changing.  

```
def fahrenheit_to_celsius(fahrenheit):
    temperature = fahrenheit - 32
    celsius = temperature * (5.0 / 9.0)
    return fahrenheit   # ❌ should be `return celsius`
```

Everything about this function *looks* right on a skim — the math is even correct. It just returns the wrong variable at the very last line, because that line got copied from the original function and never updated.  

!!! warning "Be extra careful right after a copy-paste"  

    Just like a wet road makes you drive more carefully, treat every copy-pasted function as a small crime scene. Check the parameter names, the variable names, and especially the `return` line — that's exactly where leftover old names like to hide.  

## Return errors

Two flavors show up constantly:  

- **Returning the wrong variable** — the function runs with zero errors and sometimes even happens to give the right answer by accident, which makes it *harder* to catch, not easier.
- **Forgetting to return anything at all** — if execution reaches the end of the function without hitting a `return`, the function quietly hands back `None`.

```
def sqr(a):
    t = a * a
    # forgot: return t
```

Calling `sqr(5)` here runs perfectly fine and gives you `None`. No traceback, no red flag — just a silent wrong answer waiting to break something several lines later.  

??? question "How do I catch a missing return statement before it bites me?"  

    Print the return value the first time you test any new function, even ones that "obviously" work. `print(sqr(5))` showing `None` instead of `25` is an immediate, unmistakable tell — much faster than tracing the bug backward from wherever `None` eventually crashes your program.
