# 13.1 Modules  

Ever copy and paste the same tax function into five different scripts? Then the tax rate changes and you get to fix it five times 😓. Modules fix that.  

**script:**  
A Python file you hand to the interpreter to run.  

**module:**  
A file of Python code that other scripts, modules, or the interpreter can import and use.  

**import:**  
Runs the code in the module and makes its definitions available to whoever imported it.  

We covered the basics back in [module basics](../ch02/2.8-module-basics.md). Here we go a little deeper.  

```
# Lets say this lives in pay_tools.py
TAX_RATE = 0.2

def net_pay(gross):
    return gross * (1 - TAX_RATE)
```

```
# Lets use it from another file in the same folder
import pay_tools

# Lets call the function with dot notation
print(pay_tools.net_pay(5000))
```

Output: `4000.0`  

!!! warning "File names matter"  

    - The file must end in `.py`, and you import it **without** the extension. `pay_tools.py` becomes `import pay_tools` ✅  
    - `import pay_tools.py` ❌  
    - Imports are case-sensitive. `import Pay_Tools` is not the same module ❌  
    - Put imports at the top of the file so readers see the dependencies right away.  

## What happens when you import  

1. Python checks `sys.modules` to see if the module was already imported. If so, it reuses it.  
2. If not, it creates a new module object and stores it in `sys.modules`.  
3. It runs the module's code inside that module's own namespace.  
4. The module's name gets added to your namespace so you can use dot notation.  

??? question "If I import the same module twice, does it run twice?"  

    Nope. The second `import` finds it in `sys.modules` and just reuses it. The code only runs once per program 🌕.  

??? example "🦖 Example"  

    ```
    import pay_tools

    # Lets overwrite the tax rate inside the module
    pay_tools.TAX_RATE = 0.3
    print(pay_tools.net_pay(5000))
    ```

    Output: `3500.0`  

    This change only lives while your program runs. Restart and the file's original `0.2` is back.
