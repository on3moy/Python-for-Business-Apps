# 6.6 Function stubs  

You already met the incremental habit in [developing programs incrementally](../ch05/5.9-developing-programs-incrementally.md) — build a little, test it, build a little more. Function stubs are that same habit applied to functions you know you'll need but haven't written yet.  

**function stub:**  
A function definition whose body isn't finished — a placeholder that lets you sketch a program's shape before filling in every detail.  

??? example "🦖 Example"  

    ```
    def steps_to_feet(num_steps):
        return num_steps * 3

    def steps_to_calories(num_steps):
        pass

    steps = int(input('Enter steps: '))
    print(f'Feet: {steps_to_feet(steps)}')
    print(f'Calories: {steps_to_calories(steps)}')
    ```

    Output: `Calories: None`

    `pass` does nothing except satisfy Python's rule that a function body can't be empty. The program runs top to bottom without crashing, even though `steps_to_calories()` isn't actually implemented yet.  

## Three ways to stub a function

| Approach | What it does | When to use it |
|-|-|-|
| `pass` | Silently does nothing, returns `None` | Earliest sketch of a program's structure |
| `print()` + `return -1` | Flags itself loudly when called | Once other code starts depending on the return value |
| `raise NotImplementedError` | Halts the program entirely | When the rest of the program genuinely cannot proceed without this function |

```
def steps_to_calories(steps):
    print('FIXME: finish steps_to_calories')
    return -1
```

!!! tip "Reserved Words"  

    `pass` and `raise` are both reserved words, same family as `def` and `return` — Python treats them specially and you can't repurpose them as variable names.  

??? question "Why not just skip the stub and write real code from the start?"  

    Because a half-finished real function tends to fail in confusing ways — you can't tell if the bug is in the logic you wrote or the logic you haven't. A stub fails loudly and predictably, and it lets the *rest* of your program get tested while that one piece is still cooking.
