# 11.1 Derived classes  

Ever copy and paste a class, change two lines, and call it a new class? Don't. That's what inheritance is for 😓.  

**derived class:**  
A class that inherits the attributes of another class, with some additions or variations of its own.  

**base class:**  
The class being inherited from. Any class can be a base class, you don't have to change it at all.  

**inheritance:**  
The derived class gets the base class's attributes and methods for free.  

```
# Lets build a base class
class Account:
    def __init__(self):
        self.owner = ''
        self.balance = 0

    def display(self):
        print(self.owner, self.balance)

# Lets derive from it by putting the base class in parentheses
class SavingsAccount(Account):
    def __init__(self):
        Account.__init__(self)  # Lets call the base class constructor
        self.rate = 0.0
```

`SavingsAccount` is really an `Account` with an interest rate on top. It gets `owner`, `balance`, and `display()` without us retyping any of it.  

!!! warning "Call the base constructor yourself"  

    Methods get inherited automatically, but **instance attributes do not**. They only exist because `__init__` created them. If your derived `__init__` doesn't call `Account.__init__(self)`, a `SavingsAccount` will have no `owner` or `balance` and you'll get an `AttributeError` the moment you touch them.  

??? question "What happens when I create a SavingsAccount?"  

    `SavingsAccount.__init__()` runs first and immediately hands the new object (as `self`) to `Account.__init__()`. That creates `owner` and `balance`. Then it returns and `SavingsAccount` carries on and creates `rate`.  

    ```
    # Lets check what we got
    acct = SavingsAccount()
    acct.owner = 'Dana'
    acct.balance = 500
    acct.display()
    ```

    Output:
    `Dana 500`  

## Ways to derive

- A derived class can be a base class too: `class StudentSavings(SavingsAccount)` ✅  
- One base class can have many derived classes: `class CheckingAccount(Account)` ✅  
- One class can have many base classes: `class HybridAccount(Account, Rewards)` ✅ (more on that in [mixins and multiple inheritance](11.5-mixin-classes-and-multiple-inheritance.md))
