# 13.7 Standard library  

Python ships with a big toolbox of modules. No install needed, just `import`. Before you write something yourself, check if it already exists.  

**standard library:**  
The collection of modules that come with Python.  

|Module|What it does|
|-|-|
|`datetime`|Dates, times, and the difference between them|
|`random`|Random numbers and picks|
|`copy`|Complete copies of objects|
|`time`|Current time, sleeping|
|`math`|Math functions|
|`os`|Talk to the operating system|
|`sys`|Python and system settings|
|`pdb`|The interactive debugger|
|`urllib`|Request web pages|

We already met [math](../ch02/2.9-math-module.md) and [random](../ch02/2.10-random-numbers.md) earlier.  

??? example "🦖 Example"  

    ```
    import datetime

    # Lets grab today's date
    today = datetime.date.today()

    # Lets build a gap of 30 days, like an invoice due date
    net_30 = datetime.timedelta(days=30)

    # Lets add them and format it nicely
    due = today + net_30
    print(due.strftime('%B %d, %Y'))
    ```

    Dates in Excel are always a headache. `datetime` makes date math painless 🤯
