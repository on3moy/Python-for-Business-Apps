# 6.11 Namespaces and scope resolution  

6.10 told you *where* a variable is visible. This section is the mechanism underneath that — how Python actually keeps track of it.  

**namespace:**  
A mapping of names to objects — literally a Python dictionary under the hood, where the keys are the names you typed and the values are the objects they're bound to.  

```
print(globals())

my_var = 'This is a variable'
print(globals())
```

Output:
```
{}
{'my_var': 'This is a variable'}
```

`globals()` shows you the global namespace directly, and `locals()` does the same for whichever local namespace is currently active. Watching `my_var` appear the instant it's assigned is the whole trick — a namespace only knows about a name after that name's first assignment.  

## Scope resolution order

When the interpreter hits a name in your code, it checks namespaces in a fixed order:  

1. **Local scope** — inside the currently running function, if any  
2. **Global scope** — everything defined outside any function  
3. **Built-in scope** — `int()`, `str()`, `list()`, `range()`, and the rest of what Python ships with

If the name isn't found in any of the three, you get `NameError`. This searching process has a name of its own.  

**scope resolution:**  
The process of checking local, then global, then built-in namespaces to find where a name is defined.  

??? example "🦖 Example"  

    ```
    daily_cals = 2300

    def roll():
        number = 1
        return number

    roll()
    ```

    `daily_cals` lives in the global namespace. When `roll()` runs, Python creates a brand-new local namespace holding `number` — and that namespace is deleted the moment `roll()` returns.  

??? question "What happens if I define a function called `list()`?"  

    Nothing crashes — your `list` in the global namespace simply shadows the built-in `list()` for the rest of the file. Anywhere after that definition, calling `list()` runs *your* function, not the built-in. It's legal, and it's also a great way to confuse yourself later, so name things carefully.
