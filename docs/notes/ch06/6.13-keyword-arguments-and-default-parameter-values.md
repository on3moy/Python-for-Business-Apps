# 6.13 Keyword arguments and default parameter values  

A function with seven parameters is asking for trouble the moment somebody calls it and swaps two arguments by accident. Python gives you two tools to make that call safer to write and easier to read.  

## Keyword arguments

**keyword argument:**  
An argument passed as `name=value` at the call site, matching a parameter by its name instead of by its position in the list.  

```
def print_book(title, author, year):
    print(f'{title} by {author} ({year})')

print_book(year=1954, title='The Fellowship of the Ring', author='Tolkien')
```

Order stops mattering entirely once you're using keyword arguments — Python matches each one to its parameter by name, not by position.  

!!! warning "Keyword arguments must come last"  

    You can mix positional and keyword arguments in one call, but every positional argument has to come *before* any keyword argument.  

    - ✅ `split_check(125.00, tip_percentage=0.15, num_people=2)`
    - ❌ `split_check(tip_percentage=0.15, 125.00, num_people=2)` — positional argument snuck in after a keyword one

## Default parameter values

**default parameter value:**  
A value assigned in the function definition itself, used automatically whenever the caller omits that argument.  

```
def print_date(day, month, year, style=0):
    if style == 0:
        print(f'{month}/{day}/{year}')
    else:
        print(f'{day}/{month}/{year}')

print_date(30, 7, 2012)          # style defaults to 0
print_date(30, 7, 2012, 1)       # style explicitly overridden
```

If a parameter has no default, omitting its argument is always an error — positionally, only trailing parameters can be skipped this way.  

!!! warning "Never use a mutable object as a default value"  

    ```
    def append_to_list(value, my_list=[]):
        my_list.append(value)
        return my_list
    ```

    That `[]` is created exactly **once**, when the function is defined — not once per call. Every call that skips `my_list` shares and mutates the *same* list, so it keeps growing across unrelated calls.  

    Fix it with `None` as a sentinel instead:  

    ```
    def append_to_list(value, my_list=None):
        if my_list is None:
            my_list = []
        my_list.append(value)
        return my_list
    ```

Mixing keyword arguments with default values is where this really pays off — if every parameter has a default, a caller can supply just the ones they care about, in any order: `print_date(style=1)` works fine on its own.
