# 14.3 Interacting with file systems  

Your files live inside folders, and the operating system controls all of it. The `os` module is how Python talks to it. It ships with the [standard library](../ch13/13.7-standard-library.md), so just `import os`.  

**path separator:**  
The character between folders. Windows uses `\`, Mac and Linux use `/`.  

**portability:**  
Whether your script still works on someone else's computer.  

## Don't hardcode paths  

```
import os

# Lets build the path the right way for whatever OS we are on
path = os.path.join('reports', '2026', 'q1.csv')
print(path)
```

Windows gives `reports\2026\q1.csv`, Mac gives `reports/2026/q1.csv`. `'reports\\2026\\q1.csv'` ❌ will break on a Mac.  

## Questions about a path  

|Function|Description|  
|-|-|  
|`os.path.exists(path)`|`True` if anything is there|  
|`os.path.isfile(path)`|`True` if it is a file, not a folder|  
|`os.path.getsize(path)`|Size in bytes|  
|`os.path.split(path)`|Tuple of folder and last piece|  
|`os.remove(path)`|Deletes the file|

## Walking a folder tree  

**os.walk():**  
Visits every folder under a path, handing you the folder name, its subfolders, and its files.  

```
import os

# Lets find every csv under the exports folder
for dirname, subdirs, files in os.walk('exports'):
    for name in files:
        if name.endswith('.csv'):
            print(os.path.join(dirname, name))
```

Handy when you know a file is in there somewhere but not exactly where 👉 like a pile of monthly extracts.
