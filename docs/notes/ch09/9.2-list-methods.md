# 9.2 List methods

[List basics](../ch03/3.2-list-basics.md) already covered `append()`, `pop()`, and `remove()`. Here's the rest of the toolbox — inserting mid-list, adding a whole batch at once, sorting and reversing.  

**method:**
A list method modifies or reports on the list it's called on, most of them in place.  

## Adding elements

|Method|Description|
|-|-|
|`list.append(x)`|Add `x` to the end.|
|`list.extend([x])`|Add every item in `[x]` to the end.|
|`list.insert(i, x)`|Insert `x` before position `i`.|

??? example "🦖 Example"

    `append()` vs `extend()` is the one people mix up.  

    ```
    my_list = [5, 8]

    # append adds the whole thing as ONE new element
    my_list.append([4, 12])
    print(my_list)
    ```

    Output:
    `[5, 8, [4, 12]]` ❌ (probably not what you wanted)

    ```
    my_list = [5, 8]

    # extend unpacks it and adds each item
    my_list.extend([4, 12])
    print(my_list)
    ```

    Output:
    `[5, 8, 4, 12]` ✅

## Removing elements

|Method|Description|
|-|-|
|`list.remove(x)`|Remove the first item equal to `x`.|
|`list.pop()`|Remove and return the last item.|
|`list.pop(i)`|Remove and return the item at position `i`.|

## Modifying and reporting

|Method|Description|
|-|-|
|`list.sort()`|Sort the list in place, lowest to highest.|
|`list.reverse()`|Reverse the list in place.|
|`list.index(x)`|Return the index of the first item equal to `x`.|
|`list.count(x)`|Count how many times `x` appears.|

!!! tip "Prefer methods over manual slicing tricks"

    You could write `my_list[len(my_list):] = [val]` to add an element, or `del my_list[0]` to remove one. Don't. `append()` and `pop()` say exactly what you're doing, and anyone reading your code six months from now (including you) will thank you.  

`list.sort()` and `list.reverse()` rearrange the list in place — the underlying object changes. `list.index()` and `list.count()` just report back a value; they never touch the list itself.
