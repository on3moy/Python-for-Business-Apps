# 8.1 String Slicing

We already touched slicing back in [string basics](../ch03/3.1-string-basics.md) — grabbing `'wowmom'[:3]` to get `'wow'`. Now lets go deeper: negative indices, omitted bounds, and a third argument you probably haven't met yet, the stride.  

**index:**
An index is an integer matching a specific position in a string's sequence of characters, counted left to right starting at 0.  

**slice:**
A slice is a new string, pulled from an existing one, using the notation `my_str[start:end]`. It contains the characters from `start` up to, but not including, `end`.  

```
url = 'http://en.wikipedia.org/wiki/Turing'
domain = url[7:23]
print(domain)
```

Output:
`en.wikipedia.org`

!!! warning "The end index is exclusive"

    `my_str[0:4]` on `'John Doe'` gives you indexes 0, 1, 2, and 3 — the `J`, `o`, `h`, `n`. Index 4 (the space) never makes it in. This trips people up constantly, so just remember: the end number tells you where to stop, not where to include.  

## Omitting the start or end

You don't have to give slicing both numbers.  

- `my_str[:5]` reads everything from index 0 through 4.
- `my_str[5:]` reads everything from index 5 to the end of the string.
- `my_str[:]` reads the whole thing.

??? example "🦖 Example"

    ```
    my_str = 'Jane Doe!?'

    # Everything except the last 2 characters
    print(my_str[0:-2])

    # Everything from index 5 onward
    print(my_str[5:])
    ```

    Output:
    ```
    Jane Doe
    Doe!?
    ```

## Negative indices

Negative numbers count from the end of the string instead of the beginning. `-1` is the last character, `-2` is second to last, and so on.  

??? question "Why would I ever use a negative index instead of just counting?"

    Because you don't always know the length of the string ahead of time! If you're chopping a `.csv` extension off a filename that could be any length, `my_str[:-4]` (drop the last 4 characters) works no matter how long the filename is. Counting forward from 0 would require you to already know the length — which defeats the purpose.  

## The slice stride

A third number can be added to slice notation: `my_str[start:end:stride]`. The stride is how many characters to skip after each one you read — it defaults to 1.  

```
numbers = '0123456789'

print(f'All numbers: {numbers[::]}')
print(f'Every even number: {numbers[::2]}')
print(f'Every third number between 1 and 8: {numbers[1:9:3]}')
```

Output:
```
All numbers: 0123456789
Every even number: 02468
Every third number between 1 and 8: 147
```

!!! note "A slice makes a brand new object"

    Strings are [immutable](../ch03/3.3-tuple-basics.md), so a slice can't share memory with the original. Reassigning the variable you sliced from does not change a slice you already saved off it.  

    ```
    my_str = 'The cat jumped the brown cow'
    animal = my_str[4:7]

    my_str = 'The fox jumped the brown llama'
    print(f'The animal is still a {animal}')
    ```

    Output:
    `The animal is still a cat`
