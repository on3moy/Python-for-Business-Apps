# The command line

---

## Why bother with CLI

We use the CLI to talk to the operating system without a **GUI**.

It feels like a step backwards for about a week. Then it feels like a
superpower.

---

## Check it worked

```bash
python --version
```

If that prints a version number, you are done.

If it says "not recognized", PATH was not checked during install.

# Anaconda

---

## What Anaconda gives you

- Python, already installed
- Hundreds of data packages, already installed
- `conda`, to manage environments

Useful when you do not want to assemble the toolkit yourself.

---

## Which do I actually need?

You need **Python + VS Code** for this class.

Anaconda is a convenience, not a requirement. Install it if you want the data
stack handed to you in one download.
