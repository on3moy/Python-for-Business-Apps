# How to Use This Site

This site is not really a textbook you read front to back. The zyBook already
does that job. This is the pile of notes I take into lecture, wired together so
you can pull out the one thing you actually need at 11pm the night before an
assignment is due.

Here's how to get at it.

## Search is the fastest way in

Press <kbd>S</kbd> anywhere and start typing. Search covers the full text of
every note, so `f-string`, `modulo`, or `dictionary` will get you there faster
than clicking through the nav.

## Notes link to each other

When a note mentions something covered elsewhere, it links there. Follow those
links — that's usually the fastest way to fill a gap, and how topics that span
chapters connect. Strings, for example, start in Chapter 2 and come back in
Chapter 3.

## Chapter hubs

Each chapter has a landing page listing its sections in order with a one-line
description. If you *do* want to read a chapter straight through, start there.

## Slides

Lecture decks live under [Slides](../slides/index.md). Ctrl + Click to open one
in a new tab, then press <kbd>F</kbd> for fullscreen.

## Dark mode

Top right, next to the search bar. Your eyes will thank you.
