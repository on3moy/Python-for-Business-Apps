# 5.13 Additional practice: Dice statistics  

A capstone-flavored practice problem for the chapter — nothing new to learn here, just every loop tool from this chapter working together on one program.  

The task: roll two dice a bunch of times, and print a text histogram of how often each possible sum (2 through 12) came up. This is basically the [random number](../ch02/2.10-random-numbers.md) material from chapter 2 wearing a loop-heavy outfit.  

## Building it incrementally

Following [developing programs incrementally](5.9-developing-programs-incrementally.md), do not try to write the whole thing at once.  

**Step 1 — get the counting logic right for one roll.**  

```
import random

die1 = random.randint(1, 6)
die2 = random.randint(1, 6)
roll_sum = die1 + die2

print(roll_sum)
```

**Step 2 — repeat that a fixed number of times and tally results into a dictionary keyed by sum.**  

```
counts = {}
for total in range(2, 13):
    counts[total] = 0

for roll in range(1000):
    die1 = random.randint(1, 6)
    die2 = random.randint(1, 6)
    roll_sum = die1 + die2
    counts[roll_sum] += 1
```

**Step 3 — let the user keep asking for more rolls, stopping when they enter a number less than 1.**  

```
num_rolls = int(input('How many rolls? (enter 0 to stop) '))

while num_rolls >= 1:
    for roll in range(num_rolls):
        die1 = random.randint(1, 6)
        die2 = random.randint(1, 6)
        counts[die1 + die2] += 1
    num_rolls = int(input('How many more rolls? (enter 0 to stop) '))
```

**Step 4 — print the histogram, using enumerate-style bookkeeping on the dictionary.**  

```
print('Dice roll histogram:\n')
for total, count in counts.items():
    print(f'{total}s: {"*" * count}')
```

Output (shape, exact counts will vary):  
```
Dice roll histogram:

2s: **
3s: ****
4s: ***
5s: ********
6s: *************
7s: *****************
8s: *************
9s: *********
10s: **********
11s: *****
12s: **
```

!!! tip "To Summarize"  

    This one program leans on a nested structure (a for loop rolling dice, sitting inside a while loop that asks "roll again?"), a dictionary for counting instead of a dozen separate variables, and string multiplication to draw the bars. Every piece of it is straight out of this chapter — nothing here needed a new concept, just the old ones combined.
