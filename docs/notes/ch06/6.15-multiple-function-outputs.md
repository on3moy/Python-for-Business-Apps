# 6.15 Multiple function outputs  

6.1 was firm about this: a `return` statement hands back exactly one value. So what do you do when a function genuinely has two or three things to report — say, a mean *and* a standard deviation?  

You cheat, in the most sanctioned way possible: you pack everything into one container and return *that*.  

??? example "🦖 Example"  

    ```
    def get_grade_stats(scores):
        mean = sum(scores) / len(scores)
        tmp = sum((score - mean) ** 2 for score in scores)
        std_dev = (tmp / len(scores)) ** 0.5
        return mean, std_dev

    average, standard_deviation = get_grade_stats([75, 84, 66, 99, 51, 65])
    print(f'Average: {average}')
    print(f'Std dev: {standard_deviation}')
    ```

    Output:
    ```
    Average: 73.33333333333333
    Std dev: 15.260697523012796
    ```

`return mean, std_dev` builds and returns a [tuple](../ch03/3.3-tuple-basics.md) with no parentheses needed — the comma alone is what tells Python to create one. `return (mean, std_dev)` means the exact same thing, and `return [mean, std_dev]` would work too, packed into a list instead.  

**unpacking:**  
Assigning multiple variables at once from a single sequence, matching each variable to the sequence's elements in order — `average, standard_deviation = get_grade_stats(...)` unpacks the returned tuple's two elements into two separate names in one line.  

- ✅ `return mean, std_dev` — one tuple, two values inside it
- ✅ `average, std = get_grade_stats(scores)` — unpacked back into two names
- ❌ thinking `return a, b` is somehow two separate return statements — it's still one tuple, one `return`

!!! note "Note"  

    Nothing stops you from returning three, four, or more values this way — `return a, b, c` is still just a three-element tuple. The function is still only ever returning one object; that object just happens to hold multiple things.
