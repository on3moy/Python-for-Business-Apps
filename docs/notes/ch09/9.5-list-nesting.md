# 9.5 List nesting

A list can hold any object type as an element — including another list. Stacking lists inside lists is called nesting, and it's how you represent a table, a spreadsheet, or a grid without pulling in any extra library.  

**list nesting:**
Embedding a list inside another list. `my_list = [[5, 13], [50, 75, 100]]` creates a list of two elements, and each element is itself a list.  

```
my_list = [[10, 20], [30, 40]]

print(my_list[0])
print(my_list[0][0])
```

Output:
```
[10, 20]
10
```

The first `[0]` gets you the nested list. The second `[0]` reaches inside that nested list to get an actual number.  

## Thinking of it as rows and columns

The most common use is a two-dimensional table — think a tic-tac-toe board or a spreadsheet of daily numbers by region.  

??? example "🦖 Example"

    ```
    tic_tac_toe = [
        ['X', 'O', 'X'],
        [' ', 'X', ' '],
        ['O', 'O', 'X']
    ]

    # Row 1, column 1 — the center square
    print(tic_tac_toe[1][1])
    ```

    Output:
    `X`

    `[row][column]` — row first, column second. Always in that order.  

## Iterating with a nested loop

To touch every cell in a table, you nest a for loop inside another for loop: the outer loop walks the rows, the inner loop walks each row's columns.  

```
currency = [
    [1.00, 5.00, 10.0],   # US Dollars
    [0.75, 3.77, 7.53],   # Euros
]

for row in currency:
    for cell in row:
        print(cell, end=' ')
    print()
```

Output:
```
1.0 5.0 10.0
0.75 3.77 7.53
```

!!! tip "Nesting depth is arbitrary"

    You're not limited to two dimensions. `nested_table[1][1][1]` is perfectly valid Python for a three-level structure. It gets hard to read fast, though — most business data fits fine in two dimensions (rows and columns), which is exactly the shape a spreadsheet or a database table already takes.
