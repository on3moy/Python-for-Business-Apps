# 5.11 Loop else  

This one surprises almost everybody the first time they see it — loops can have an `else` clause too, and it has nothing to do with an if branch failing.  

**loop else:**  
A block attached to a while or for loop that runs only if the loop finished all its iterations normally — meaning nobody hit a [break statement](5.10-break-and-continue.md) along the way.  

```
for name in iterable:
    # runs once per item
else:
    # runs only if the loop finished without a break

# runs after everything, break or not
```

??? example "🦖 Example"  

    ```
    names = ['Janice', 'Clarice', 'Martin', 'Veronica', 'Jason']
    num_to_print = 2

    for i in range(len(names)):
        if i == num_to_print:
            break
        print(names[i], end=' ')
    else:
        print('All names printed.')
    ```

    Output:  
    `Janice Clarice`  

    `break` fires when `i` hits 2, so the `else` never runs — "all names printed" would be a lie in this case. Bump `num_to_print` to something bigger than the list, and the loop runs to completion, `break` never fires, and the `else` message prints.  

??? question "Why not just put that message after the loop instead of in an else?"  

    Because "after the loop" runs **every time**, break or no break. The whole point of loop `else` is that it only fires on the clean, un-interrupted finish. It is exactly the tool you want for "search finished and I never found a match" style logic — searching a list for a name, hitting `break` the moment you find it, and only printing "not found" in the `else` if the whole list got searched without a hit.  

!!! tip "Reserved Words"  

    Treat loop `else` as answering the question "did this loop get interrupted by a break?" — not "did the condition ever come back False?" Those sound similar but they are not the same thing, and mixing them up is the most common misread of this construct.
