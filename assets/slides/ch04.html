An implicit range leans on the fact that elif only runs if every branch above it failed — so each condition only needs to state its lower bound, and the previous branch's failure quietly supplies the upper bound. This reads cleanly when your ranges are continuous with no gaps between them.

An explicit range spells out both bounds with and, which is the right choice the moment your ranges have a gap between them or you genuinely need to test an upper bound rather than relying on elif's fall-through behavior. Neither style is more correct than the other — pick whichever reads more clearly for the range you are describing.

Two standalone if statements are evaluated independently — Python checks the first, then, regardless of the outcome, checks the second on its own terms. A customer who is both high-balance and long-tenured prints both labels. Nothing about the first condition constrains the second.

Chain the same two conditions with elif instead, and the second branch only gets evaluated if the first one failed — so at most one label ever prints, even for that same high-balance, long-tenured customer.
