# Chapter 12: Exceptions

## 12.1 Handling exceptions using try and except

Risky code goes in a `try` block. If it fails, Python skips the rest of the `try` and runs the `except` block, then keeps going.

```python

#       print 'Could not convert' from an except block. Then print 'Still running!'
#       after the whole thing.
```

## 12.5 Using finally to clean up

A `finally` block always runs, whether or not an exception happened. It goes last, after any `except` blocks.

```python
def divide(a, b):
    result = -1
    # TODO: in a try block, set result to a / b. Add an except for
    #       ZeroDivisionError that prints 'Cannot divide by zero'. Add a finally
    #       block that prints the result.

divide(10, 0)
```
