# 5.5 For loops  

Every while loop we have written so far has been counting or watching for a sentinel. A for loop is for a different, extremely common job: walk through every item in a container, one at a time.  

**for loop:**  
Iterates over each element in a container, assigning a variable to the current element on every pass through the loop body, until every element has been visited.  

```
for variable in container:
    # runs once per item in container

# runs after every item has been visited
```

??? example "🦖 Example"  

    ```
    for name in ['Kai', 'Sam', 'Alex']:
        print(f'Hi {name}!')

    print('Done')
    ```

    Output:  
    ```
    Hi Kai!
    Hi Sam!
    Hi Alex!
    Done
    ```

    No counter, no condition to write yourself — the for loop just knows to stop when the [list](../ch03/3.2-list-basics.md) runs out.  

## Strings and dictionaries work too

A string is a sequence type, so a for loop walks character by character. A [dictionary](../ch03/3.4-dictionary-basics.md) hands you the keys, in insertion order — you look up the value yourself if you need it.  

```
for char in 'Yes':
    print(char)

channels = {'MTV': 35, 'CNN': 28}

for name in channels:
    print(f'{name} is on channel {channels[name]}')
```

Output:  
```
Y
e
s
MTV is on channel 35
CNN is on channel 28
```

!!! note "Note"  

    Looping over a dictionary gives you **keys**, never values. `for value in channels:` is a misleading variable name — you would still be getting `'MTV'` and `'CNN'`, not `35` and `28`.  

## A running total from a for loop

The revenue-tracking version of what we did with while loops — walk the list, keep a running sum, divide by the count at the end.  

```
daily_revenues = [2350.25, 1800.50, 1795.00, 2050.25]

total = 0
for day in daily_revenues:
    total += day

average = total / len(daily_revenues)
print(f'Average: ${average:.2f}')
```

Output:  
`Average: $1998.75`  

## Looping backward

`reversed()` flips the order the for loop walks through, without touching the original container.  

```
names = ['Biffle', 'Bowyer', 'Busch']

for name in reversed(names):
    print(name, end=' ')
```

Output:  
`Busch Bowyer Biffle`
