## 13.5 Reloading modules

A module only runs once per import, so edits to the file are not noticed. The cell below creates `rate_card.py` and imports it.

```python

with open('rate_card.py', 'w') as f:
```

## 13.5 Reloading modules -- the from import trap

A name copied with `from` is a separate copy. Reloading the module does not refresh it.

```python
from importlib import reload
import rate_card
from rate_card import RATE

with open('rate_card.py', 'w') as f:
    f.write('RATE = 0.3\n')
```

## 13.6 Packages
