# 6.17 Engineering examples  

Two worked examples to close out the chapter — same tools from 6.1-6.16, applied to actual physics formulas instead of pizzas and sandwiches.  

## Gas equation

The ideal gas law, PV = nRT, relates a gas's pressure, volume, temperature, and mole count through a constant R. Solve for temperature and it becomes a one-line function.  

```
gas_constant = 8.3144621  # Joules / (mol*Kelvin)

def convert_to_temp(pressure, volume, mols):
    """Convert pressure, volume, and moles to a temperature"""
    return (pressure * volume) / (mols * gas_constant)

print(f'Temperature = {convert_to_temp(2500, 35.5, 18):.2f} K')
```

Output: `Temperature = 593.01 K`

`gas_constant` is defined once as a [global variable](6.10-scope-of-variables-and-functions.md) outside the function, exactly the kind of use case where a global is genuinely the right call — it's a physical constant, not something any function should ever be modifying.  

## Trajectory of an object on Earth

A projectile's x and y position at time `t`, given initial velocity `v` and launch angle `a`, comes from two standard physics equations: `x = v * t * cos(a)` and `y = v * t * sin(a) - 0.5 * g * t * t`. Since the function needs to hand back both coordinates at once, it leans on the same trick from [multiple function outputs](6.15-multiple-function-outputs.md) — pack them into a tuple.  

```
import math

def trajectory(v, angle_deg, t):
    angle = math.radians(angle_deg)
    x = v * t * math.cos(angle)
    y = (v * t * math.sin(angle)) - (0.5 * 9.81 * t * t)
    return x, y

x_loc, y_loc = trajectory(50, 45, 2)
print(f'x: {x_loc:.2f}, y: {y_loc:.2f}')
```

A [for loop](../ch05/5.5-for-loops.md) calling `trajectory()` once per second, checking `y_loc > 0` after each call, is exactly how you'd generate the object's full path — and the loop's body stays short precisely because all the math lives inside the function instead of getting rewritten every iteration.  

!!! note "Note"  

    Swapping `float()` for `int()` on the inputs here would meaningfully distort the result — angles and velocities in physics formulas routinely need the fractional precision that integers throw away.
