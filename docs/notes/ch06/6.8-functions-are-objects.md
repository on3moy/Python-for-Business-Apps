# 6.8 Functions are objects  

Remember from [objects](../ch02/2.3-objects.md) back in Chapter 2 — everything in Python has a type, an identity, and a value. Functions are no exception, which is a genuinely weird thing to sit with the first time you hear it.  

**function object:**  
`def print_face():` doesn't just describe behavior — it creates an actual object, with `print_face` as a name bound to it, the same way `x = 5` binds `x` to an integer object.  

Because a function is just an object, you can do ordinary object things to it — assign it to another name, pass it as an argument, store it in a list.  

??? example "🦖 Example"  

    ```
    def print_cat():
        print('meow')

    func = print_cat
    func()
    ```

    Output: `meow`

    `func = print_cat` doesn't call the function — no parentheses, so nothing runs. It just creates a second name pointing at the exact same function object. `func()` and `print_cat()` are now two different ways to trigger the identical call.  

## Passing a function as an argument

```
def print_human_head():
    print('o o')

def print_monkey_head():
    print('( o o )')

def print_figure(face):
    face()
    print('| --|-- |')

print_figure(print_monkey_head)
```

`print_figure()` never has to know or care which face function it received — it just calls whatever was handed to it. That's the same flexibility [dynamic typing](6.3-dynamic-typing.md) gives you everywhere else in Python, applied to functions specifically.  

!!! warning "Don't confuse the object with the call"  

    - ✅ `func = print_cat` — assigns the function object itself
    - ❌ `func = print_cat()` — calls it immediately and assigns whatever it *returns* (here, `None`)

    That missing pair of parentheses is the entire difference between "here's a function to use later" and "run this right now."  

??? question "Is `my_func1 + my_func2` valid?"  

    No — functions only support the call operation (`()`). They don't support `+`, `-`, or comparisons the way numbers and strings do, even though they're objects too.
