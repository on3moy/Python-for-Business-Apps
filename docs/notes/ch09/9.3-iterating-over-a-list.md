# 9.3 Iterating over a list

You already know the [for loop](../ch05/5.5-for-loops.md) shape — `for my_var in my_list:` hands you each element one at a time. This is the single most common thing you'll do with a list, so let's talk about the patterns that come up constantly.  

## Tracking a value while you loop

A lot of list tasks boil down to "walk every element, remember something as you go." Finding the largest even number is a good example — you can't just call `max()`, because you need a condition first.  

??? example "🦖 Example"

    ```
    nums = [1, 4, 15, 456]

    max_even = None
    for num in nums:
        if num % 2 == 0 and (max_even is None or num > max_even):
            max_even = num

    print(max_even)
    ```

    Output:
    `456`

!!! warning "Don't seed your tracking variable with 0"

    It's tempting to start `max_even = 0` instead of `None`. But if every number in the list is negative, `0` isn't actually the largest value seen — it's a value that was never in the list at all. `None` means "nothing found yet" and can't be confused with a real answer.  

## Built-in shortcuts

Iterating to find a max, min, or sum is so common Python gives you a function for it, so you don't have to write the loop yourself.  

|Function|Description|
|-|-|
|`sum(list)`|Total of all elements.|
|`max(list)`|Largest element.|
|`min(list)`|Smallest element.|
|`any(list)`|`True` if any element is truthy.|
|`all(list)`|`True` if every element is truthy.|

Input:
`sum([-3, 5, 25])`
Output:
`27`

## Getting the index too

A plain for loop only hands you the value, not its position. If you need both, wrap the list in [`enumerate()`](../ch05/5.12-enumerate.md) instead of managing a separate counter yourself.  

```
tokens = ['red', 'green', 'blue']

for index, value in enumerate(tokens):
    print(f'{index}: {value}')
```

Output:
```
0: red
1: green
2: blue
```

??? question "What happens if I try to access an index that doesn't exist?"

    Python raises an `IndexError` and aborts the program. For a list with 8 elements, `my_list[10]` doesn't quietly return `None` — it stops execution. Always check `len(my_list)` before trusting an index a user typed in.
