Up to now our code has run top to bottom, every line, every time. That stops here.  

**branch:**  
A sequence of statements only executed under a certain condition.  

**if branch:**  
A branch taken only if an expression is true.  

!!! info " "  

    Anyone who has worked a hostess stand already knows this one. Party of 1? Seat them at the counter. Party of 2? Small table. Anything else? Big table. You just wrote an if-elseif-else.  

## Making a decision  

The condition is any [expression](../ch02/2.6-python-expressions.md) that comes out True or False.  

```
# Lets give a discount to our long time customers
years_active = 7

if years_active > 5:
    discount = 0.10
```

Notice the colon, and notice the indent. Both matter. Python figures out what belongs to the branch by [whitespace](../ch01/1.9-why-whitespace-matters.md), not by curly braces like other languages.  

## if-else  

**if-else branch:**  
Has two branches. The first runs if the expression is true, else the other one runs.  

```
# Lets set an insurance rate
driver_age = 22

if driver_age < 25:
    insure_price = 4800
else:
    insure_price = 2200
```

One of those two lines runs. Never both, never neither.  

## When two isn't enough  

Commonly you want one of three or more branches. Chain them with elif.  

??? example "🦖 Example"  

    ```
    # Lets figure out an anniversary gift
    num_years = 25

    if num_years == 1:
        print('Newlyweds')
    elif num_years == 25:
        print('Silver')
    elif num_years == 50:
        print('Golden')
    else:
        print('Congrats')
    ```

    Each expression is checked in order. The **first** one that comes back True wins, and the rest are skipped entirely.  

!!! note "Note"  

    The else is optional. Leave it off and it is perfectly possible that no branch runs at all. Sometimes that is what you want. Usually it is a bug you have not found yet.
