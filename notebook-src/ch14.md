## 14.5 Command-line arguments and files

`sys.argv` is the list of values typed after the script name. `sys.argv[0]` is the script itself. The cell below creates `sales_march.txt` and then runs a script file through `subprocess` the way you would from a terminal.

```python
import subprocess
import sys

with open('sales_march.txt', 'w') as f:
    f.write('1500\n2200\n')

# TODO: write a script file named first_amount.py (open it with 'w') whose

                        capture_output=True, text=True)

```

## 14.5 Command-line arguments and files -- checking and exit codes

A good script checks its arguments and tells the operating system when something went wrong. Exit code `0` means success; anything else means failure.

```python
import subprocess
import sys

# TODO: rewrite first_amount.py (open it with 'w') so that it prints a usage
#       message and exits with code 1 unless it got exactly one argument, and
#       prints 'File does not exist.' and exits with code 1 if that file is
#       missing. Otherwise it should behave as before.

for args in [[], ['no_such_file.txt'], ['sales_march.txt']]:
    result = subprocess.run([sys.executable, 'first_amount.py'] + args,
                            capture_output=True, text=True)
    print(args, '->', result.returncode, result.stdout.strip())
```
