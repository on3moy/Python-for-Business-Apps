# 5.6 Counting using the range() function  

[For loops](5.5-for-loops.md) walk a container. But what if there is no container yet — you just want to run something exactly 10 times? That is what `range()` is for.  

!!! abstract "range()"  

    `range()` generates a sequence of integers, starting at a value that is included, ending before a value that is not included, stepping by an amount you choose. It takes up to three arguments.  

|Call|Sequence generated|
|-|-|
|`range(5)`|`0 1 2 3 4`|
|`range(3, 7)`|`3 4 5 6`|
|`range(0, 10, 2)`|`0 2 4 6 8`|
|`range(5, 0, -1)`|`5 4 3 2 1`|

??? example "🦖 Example"  

    ```
    for i in range(5):
        print(i)
    ```

    Output:  
    ```
    0
    1
    2
    3
    4
    ```

    One argument means "start at 0, stop before this number." That single-argument form is by far the most common one you will type.  

## The negative-step trick

Give `range()` a negative step and it counts down instead of up — but the start and stop have to flip their relationship too.  

```
for i in range(10, 0, -2):
    print(i, end=' ')
```

Output:  
`10 8 6 4 2`  

!!! warning "range(X, Y) is never inclusive of Y"  

    `range(0, 5)` stops **before** 5 — you get `0 1 2 3 4`, never `5`. This trips people coming from spreadsheet-style thinking, where a range A1:A5 includes both ends. Python ranges only include the start.  

## What kind of thing is a range?

`range()` produces its own type, not a list — it is a sequence type like a list or [tuple](../ch03/3.3-tuple-basics.md), immutable, and almost always used right inside a for loop rather than stored and inspected on its own.  

```
sequence = range(0, 100, 25)
print(sequence)
print(list(sequence))
```

Output:  
```
range(0, 100, 25)
[0, 25, 50, 75]
```

That second line is the only reason to ever wrap a `range()` in `list()` — to actually see the values it would generate.
